# Online Exam Cheating Detection Support System

온라인 시험 중 발생하는 접속 기록, 창 이탈, 답안 패턴 등의 데이터를 저장하고 분석하여 이상 행동을 탐지하는 보조 시스템입니다.

## Project Topic
온라인 시험 부정행위 탐지 보조 시스템

- 접속 기록 저장
- 창 이탈 기록 저장
- 답안 패턴 분석
- 이상 행동 탐지

## Tech Stack

- Main Language: Python
- Backend: FastAPI
- Database: PostgreSQL
- Frontend: HTML, CSS, JavaScript
- Container: Docker
- Server OS: Ubuntu
- Version Control: GitHub
